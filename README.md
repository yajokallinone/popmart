# CMU OPEN HOUSE 2026 · ENG BOX Gacha Cabinet

เว็บตู้กาชาปองกล่องสุ่ม 3D แบบโต้ตอบได้ ธีมวิศวะ (เหล็ก · เฟือง · พิมพ์เขียว) สำหรับงาน CMU Open House 2026

**Tech stack:** React 19 · React Three Fiber · Drei · Three.js · GSAP · Zustand · Tailwind CSS v4 · Vite 8

ทำงานฝั่งเบราว์เซอร์ทั้งหมด ไม่มี backend — ข้อมูลรางวัลเก็บใน localStorage ของเครื่องที่เปิด

> ดูรายละเอียดการปรับปรุงแต่ละส่วน (ธีม เอฟเฟกต์ โมเดลข้างตู้ ฯลฯ) ได้ที่ [`SUMMARY.md`](SUMMARY.md)

## ฟีเจอร์หลัก

### ตู้และฉาก
- ตู้เหล็กค่าเริ่มต้น **3 ชั้น × 4 กล่อง = 12 กล่อง** — **ปรับจำนวนได้ 2–30 กล่อง** ในหน้า ⚙ รางวัล ตู้และฉากขยาย/หดตามอัตโนมัติ
- ป้าย ENG BOX ไฟ LED เฟืองหมุน ผนังหลังลายพิมพ์เขียว
- ข้างตู้มีเครื่องยนต์ (ซ้าย) หุ่นยนต์วิศวกร (ขวา) และ **กล่องโชว์ใบใหญ่บนแท่นหมุน** ที่ลากหมุนดูได้
- ลายกล่องใช้ภาพใน `public/textures/` (front, side, side_left, top, back)
- กล้องมี 2 โหมด: **🔒 มุมตรง** (ค่าเริ่มต้น) และ **🔄 หมุนเอง** (ลากหมุน/ซูม) — ระหว่างเปิดกล่องกล้องล็อกชั่วคราว

### การเล่น
| การกระทำ | ผลลัพธ์ |
|---|---|
| ชี้กล่อง | กล่องแกว่ง/ยื่นออกมา เส้นขอบเรืองแสง |
| คลิกกล่อง | บินมากลางจอ → เขย่าลุ้น → ฝาเปิด → โชว์รางวัลพร้อมเอฟเฟกต์ตามระดับ |
| ผลรางวัล | แสดงในแผงมุมขวาบน (ไม่บังตู้) พร้อมเฉลยกล่องอื่นที่มีของ กด ▴ / ▾ ย่อ–ขยายได้ |
| **เลือกใหม่** | กล่องบินกลับชั้น กล่องอื่นแง้มฝาเฉลยของ แล้วสับจัดรอบใหม่ |
| 🎲 Surprise me | สุ่มเลือกกล่องให้ |
| ↻ Restock | เติมสต็อกทุกรางวัลกลับเต็ม และจัดรอบใหม่ |
| ⚙ รางวัล / ✎ เพิ่ม / แก้ไขรางวัล | เปิดหน้าตั้งค่ารางวัล |

### ระบบสุ่ม (จัดของล่วงหน้าทุกรอบ — `dealRound()` ใน `src/data.js`)
- ก่อนเริ่มรอบ ระบบสุ่มของใส่กล่องทุกใบไว้ล่วงหน้า
- **Common:** การันตี 1 กล่องทุกรอบ ถ้ายังมีสต็อก (มีหลายแบบจะสุ่มเลือก 1 แบบ)
- **Rare / Secret:** ออกเป็นของแถมตาม % ที่ตั้งไว้ **ไม่เกิน 1 ชิ้นต่อรอบ** และไม่ออกพร้อมกัน
- กล่องที่เหลือเป็นกล่องว่าง → แต่ละรอบเป็นได้ Common อย่างเดียว · Common + Rare · Common + Secret
- **หักสต็อกเฉพาะกล่องที่ผู้เล่นเลือก** ของในกล่องที่ไม่มีใครเลือกไม่เสียสต็อก
- รางวัลที่คงเหลือ = 0 จะไม่ถูกจัดลงตู้

### หน้าตั้งค่ารางวัล (Admin)
- Prize Pool **เริ่มต้นว่าง** — เพิ่มรางวัลเองทั้งหมด
- ตั้งได้: รูป (อัปโหลด ย่ออัตโนมัติ หรือไม่ใส่รูป), ชื่อ, ระดับ (Common / Rare / Secret), จำนวนทั้งหมด, คงเหลือ, % โอกาสเข้าตู้ (เฉพาะ Rare / Secret; Common แสดงเป็น "การันตีทุกรอบ")
- แก้ไขรางวัลตอนตู้ว่างอยู่ ระบบจะสับจัดรอบใหม่ให้ทันที
- **จำนวนกล่องในตู้:** ปุ่ม − / ＋ หรือพิมพ์ (2–30) และเลือก "กล่องต่อชั้น" เป็นอัตโนมัติหรือกำหนดเอง (1–8) ชั้นล่างที่ไม่เต็มจะจัดกลางชั้น
- บันทึกอัตโนมัติใน localStorage: รางวัล key `cmu-open-house-prizes-v2` · ขนาดตู้ key `cmu-open-house-layout-v1`

## โครงสร้างโปรเจกต์

```
index.html              หน้าเว็บ (ชื่อแท็บ, ฟอนต์, ไอคอน)
public/
  logo.png              โลโก้ EDSERV Engineering
  textures/*.jpg        ลายกล่อง 5 ด้าน (ใช้งานอยู่ — ห้ามลบ)
assets-original/        ไฟล์ต้นฉบับของ textures
docs/                   ภาพตัวอย่างดีไซน์กล่อง
src/
  main.jsx, App.jsx     จุดเริ่มแอป: Scene 3D + Overlay + Loader
  data.js               makeLayout() จัดตารางกล่องตามจำนวน, RARITY / FX_COLOR, dealRound() / prizeOdds(), ตำแหน่งกล้องตอนเปิด (FOCUS_*)
  store.js              Zustand: สต็อก, layout ตู้ (setLayout), ผลสุ่มแต่ละกล่อง, เฟสการเปิด, โหมดกล้อง, บันทึก localStorage
  utils.js              ย่อรูปที่อัปโหลดเป็น data URL
  index.css             ธีม พื้นหลัง เคอร์เซอร์รูปมือ
  scene/
    Scene.jsx           Canvas, แสง, พื้น, กล้อง (CameraRig / Controls) — กล้องมุมตรงปรับระยะตามขนาดตู้
    Cabinet.jsx         ตู้ ชั้นวาง ป้าย ของประดับเฟือง + วางกล่องตาม layout
    EngBox.jsx          กล่อง 1 ใบ (hover, ฝาบานพับ, ออร่าตามระดับ)
    Director.jsx        ลำดับแอนิเมชันเปิดกล่องด้วย GSAP (ตาราง FX ต่อระดับ)
    Confetti.jsx        เฟืองระเบิด ฝนเฟือง วงคลื่น (ตาราง FX ต่อระดับ)
    PrizeModel.jsx      แสดงรางวัล (การ์ดรูป หรือการ์ด 3D เมื่อไม่มีรูป)
    Figure.jsx          ตัวการ์ตูน 3D แบบ procedural (ยังอยู่ในโค้ด แต่ไม่มีในรางวัลเริ่มต้น)
    Props.jsx           เครื่องยนต์ + หุ่นยนต์ข้างตู้ (ตาราง PARTY) + วาง Showcase (ขยับตามความกว้างตู้)
    Showcase.jsx        กล่องโชว์ใบใหญ่ หมุนเอง + ลากหมุนได้
    textures.js         ป้าย/ป้ายเลข/ผนังพิมพ์เขียว (canvas) + useBoxTextures() โหลดลายกล่อง
    shapes.js           รูปเฟือง gearShape()
    registry.js         Map ให้ Director เข้าถึง object ของแต่ละกล่อง
  ui/
    Overlay.jsx         หัวเว็บ, Prize Pool, ปุ่มควบคุม, แผงผลรางวัลมุมขวาบน, แฟลช, ป้าย RARE/SECRET
    AdminPanel.jsx      หน้าตั้งค่ารางวัล + จำนวนกล่องในตู้
    FigureIcon.jsx      ไอคอนรางวัล
```

ลำดับเฟสการเปิดกล่อง (`phase` ใน store): `idle → flying → shaking → opening → revealed → returning → idle`

## ปรับแต่งที่ใช้บ่อย

| อยากปรับ | แก้ที่ |
|---|---|
| จำนวนกล่อง / กล่องต่อชั้น | หน้า ⚙ รางวัล |
| ช่วงจำนวนกล่องที่ตั้งได้ | `MIN_BOXES`, `MAX_BOXES`, `MAX_COLS`, `DEFAULT_BOXES` ใน `src/data.js` |
| ขนาดกล่อง / ระยะห่างกล่องและชั้น | `BOX`, `PITCH_X`, `PITCH_Y` ใน `src/data.js` |
| สี/ชื่อระดับความหายาก | `RARITY`, `FX_COLOR` ใน `src/data.js` |
| ตำแหน่งกล้อง/กล่องตอนเปิด | `FOCUS_BOX`, `FOCUS_CAM`, `FOCUS_TARGET` ใน `src/data.js` |
| ความยาวการลุ้น กล้องกระตุก/สั่น | ตาราง `FX` ใน `src/scene/Director.jsx` |
| เฟืองระเบิด วงคลื่น | ตาราง `FX` ใน `src/scene/Confetti.jsx` |
| ท่าดีใจของหุ่นยนต์/เครื่องยนต์ | ตาราง `PARTY` ใน `src/scene/Props.jsx` |
| ขนาด/ความเร็วหมุนของกล่องโชว์ | `SCALE`, `AUTO` ใน `src/scene/Showcase.jsx` |
| ลายกล่อง | แทนไฟล์ใน `public/textures/` (ชื่อไฟล์เดิม) |
| ตำแหน่งโลโก้บนฐานตู้ | `<LogoBadge x={...} />` ใน `src/scene/Cabinet.jsx` |

## ข้อจำกัดที่ควรรู้
- ข้อมูลรางวัลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ซิงก์ข้ามเครื่อง และหน้าตั้งค่าไม่มีรหัสผ่าน
- รูปที่อัปโหลดเก็บใน localStorage ถ้ารูปเยอะ/ใหญ่เกินอาจบันทึกไม่ได้ (ดูคำเตือนใน console)
- โหมดกล้องกลับเป็น 🔒 มุมตรงทุกครั้งที่เปิดหน้าเว็บ
- `image/` (cloth.png, jewery.png) ไม่ได้ถูกใช้ในแอป
