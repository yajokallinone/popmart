# CMU OPEN HOUSE 2026 · ENG BOX Gacha Cabinet

เว็บตู้กาชาปองกล่องสุ่ม 3D แบบโต้ตอบได้ ใช้กล่องดีไซน์ตามภาพ **ENG CMU Open House 2026 × POP MART**

**Tech stack:** React 19 · React Three Fiber · Drei · Three.js · GSAP · Zustand · Tailwind CSS v4 · Vite

---

## วิธีรัน

```bash
npm install
npm run dev      # เปิด http://localhost:5173
npm run build    # build สำหรับ deploy (โฟลเดอร์ dist/)
```

> ฟอนต์ Fredoka โหลดจาก Google Fonts ต้องมีอินเทอร์เน็ตตอนเปิดครั้งแรก

## ฟีเจอร์หลัก

### ตู้และกล่อง
- ตู้สีชมพู/ลาเวนเดอร์ **3 ชั้น × 4 คอลัมน์ = 12 กล่อง** จัดใน grid คงที่ (ID 1–12) พร้อมป้ายเลขที่ขอบชั้น
- กระจกหน้าตู้ ไฟ LED ใต้ชั้น ป้าย "ENG BOX" เฟือง/หัวใจประดับ
- กล่องใช้เท็กซ์เจอร์ที่ตัดจากภาพต้นฉบับ (หน้า / ข้าง / ฝาบน) อยู่ใน `public/textures/`
- กล้องมุมสูงเล็กน้อยแบบ 3/4 ปรับระยะอัตโนมัติให้เห็นครบทั้ง 12 กล่อง และหมุนดูได้ในช่วงจำกัด

### การโต้ตอบ
| การกระทำ | ผลลัพธ์ |
|---|---|
| เอาเมาส์ชี้กล่อง | แกว่งเบา ๆ · เส้นขอบเรืองแสง · ยื่นออกมาข้างหน้า · tooltip บอกเลขกล่อง/สถานะ |
| คลิกกล่อง | กล่องลอยมากลางจอ → เขย่า → ฝาเปิด → รางวัลโผล่พร้อมคอนเฟตตี → กด **Collect** กล่องกลับที่เดิม |
| กล่องที่เปิดแล้ว | ฝาเปิดแง้ม ป้ายเลขเป็นสีเขียว ✓ คลิกซ้ำเพื่อดูรางวัลได้อีก |
| 🎲 Surprise me | สุ่มเลือกกล่องที่ยังไม่เปิด |
| ↻ Restock | คืนกล่องทั้งหมดและเติมของกลับเต็มตามจำนวนที่ตั้งไว้ |

### ระบบรางวัล (กด **⚙ รางวัล** หรือปุ่มในแผง Prize Pool)
- **อัปโหลดรูป** เพิ่มรางวัลได้ทีละหลายไฟล์ (ย่อรูปอัตโนมัติ) แล้วรูปจะลอยขึ้นเป็นการ์ดตอนเปิดกล่อง
- **กำหนดจำนวน** ทั้งหมด / คงเหลือ ของแต่ละรางวัล
- **กำหนดโอกาสเจอ** ด้วย "น้ำหนักโอกาส" — โอกาสจริง = น้ำหนัก ÷ น้ำหนักรวมของรางวัลที่ยังเหลือ (ของหมดแล้วคำนวณใหม่เอง)
- **แก้ไข/ลบ** ชื่อ ระดับ (Common / Rare / Secret) รูป และลบรางวัลได้ตลอด
- แผง **Prize Pool** มุมซ้ายแสดงของที่เหลือ + โอกาสเจอแบบเรียลไทม์
- ถ้าของหมดแต่ยังมีกล่อง จะได้ "กล่องว่าง" · ระบบเตือนเมื่อรางวัลน้อยกว่ากล่องที่เหลือ
- ข้อมูลบันทึกอัตโนมัติใน **localStorage** ของเบราว์เซอร์ (key: `cmu-open-house-prizes-v1`)

ค่าเริ่มต้น: ตัวการ์ตูน 7 แบบ (Common ×5 แบบละ 2 ชิ้น, Rare ×1, Secret ×1 = 12 ชิ้น)

## โครงสร้างโปรเจกต์

```
public/textures/        เท็กซ์เจอร์กล่อง (front, side, side_left, top, back)
src/
  data.js               ค่าคงที่ของตู้/กล่อง, รางวัลเริ่มต้น, ฟังก์ชันสุ่มและคำนวณโอกาส
  store.js              Zustand: สถานะกล่อง, รางวัล, เฟสการเปิด, บันทึก localStorage
  utils.js              ย่อรูปที่อัปโหลดเป็น data URL
  scene/
    Scene.jsx           Canvas, แสง, กล้อง, OrbitControls
    Cabinet.jsx         ตู้ ชั้นวาง กระจก LED ป้าย + วางกล่อง 12 ใบ
    EngBox.jsx      กล่อง 1 ใบ (hover, wiggle, outline, ฝาบานพับ)
    Director.jsx        GSAP timeline: บิน → เขย่า → เปิด → เก็บกลับ
    PrizeModel.jsx      แสดงรางวัล (การ์ดรูป หรือตัวการ์ตูน)
    Figure.jsx          ตัวการ์ตูน 3D แบบ procedural
    Confetti.jsx        เอฟเฟกต์เฟือง/หัวใจ
    textures.js         canvas texture (ป้าย, ป้ายเลข, ผนังหลัง ฯลฯ)
  ui/
    Overlay.jsx         ชื่อเว็บ, Prize Pool, Collection, tooltip, การ์ดผลรางวัล
    AdminPanel.jsx      หน้าตั้งค่ารางวัล
    FigureIcon.jsx      ไอคอนรางวัล
```

## ปรับแต่งที่ใช้บ่อย
- **ความเร็วเอฟเฟกต์เปิดกล่อง:** ค่า `duration` ใน `src/scene/Director.jsx`
- **ขนาด/ระยะกล่อง:** `BOX`, `PITCH_X`, `SHELF_TOP` ใน `src/data.js`
- **รางวัลเริ่มต้น/โอกาสเริ่มต้น:** `DEFAULT_QTY`, `DEFAULT_WEIGHT` ใน `src/data.js`
- **ข้อความป้ายบนตู้:** ฟังก์ชัน `signTexture` ใน `src/scene/textures.js`

## ข้อจำกัดที่ควรรู้
- ข้อมูลรางวัลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ซิงก์ข้ามเครื่อง (หน้าตั้งค่าไม่มีรหัสผ่าน)
- ผู้พัฒนายังไม่ได้ตรวจภาพตอนฝาเปิดและรางวัลโผล่ในเบราว์เซอร์จริง หากตำแหน่งหรือขนาดไม่พอดีให้ปรับค่า `FOCUS_*` ใน `src/data.js` และตำแหน่งใน `Director.jsx`
